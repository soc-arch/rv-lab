SoC Architecture Laboratory · Hands-on RISC-V

내가 쓴 코드가
CPU에서 실행되는 순간.

C 프로그램을 작성하고, 같은 실행 파일을 Spike와 교육용 RTL CPU에서 비교합니다. 명령어가 실제로 수행되는 과정을 관찰하고, 결과를 유지하면서 성능이 달라지는 이유를 설명해보세요.

Lab 01부터 시작 →전체 실습 안내정답과 실제 화면 보기
C / Assembly→Same ELF · Spike + RTL→Cycle viewer→Measured experiments

이 웹사이트는 실습 안내입니다. 명령어는 Linux 작업 환경의 터미널에서 실행합니다. 실습 후 생성되는 실행 결과와 cycle viewer는 각자의 작업 환경에서 열 수 있습니다.

C의 함수·반복문·배열과 기본 터미널 사용법을 알면 시작할 수 있습니다. FPGA나 물리 카메라 없이 실습하며, 상세 단계와 체크포인트는 영어로 제공합니다.
