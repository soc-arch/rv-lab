Historical teaching-core validation — 2026-10-11

Historical record: the results below cover the previous teaching_fetch / one-entry response-buffer CPU. They do not describe the current P1/Q0 core. Use the current P1 validation and its source/preset hashes for the default shipped core. The historical JSON is preserved as teaching-validation.json.

The standalone teaching package passed actual functional execution and student-workflow checks. The machine-readable record is teaching-validation.json. These results cover the teaching CPU and its local framework; the full verify.py driver, EDA synthesis, Formality, achieved timing, place and route, and tapeout signoff were not performed.

What passed

  • CPU regression: 47/47 expected outcomes, comprising 44 successful programs and three correctly rejected programs: nonzero return, failed known-answer check, and bounded hang.

  • Memory protocol: 20/20 cases.

  • Larger images: four camera modes and three integer visual applications at 64×48, with ball frame 24. Each backend's complete 9,216 RGB bytes matched the independent reference in every case; architectural signatures also matched.

  • Directed images: camera 8 test methods / 12 evidence outcomes (11 successes and one expected timeout with stale-output removal); visual 6 methods / 7 real firmware cases.

  • Performance: three host parsing tests and two real student-workflow tests, including O0/O2 CSR values checked against actual instruction retirement, complete retirement-count agreement, and a correctly rejected failed custom program.

  • Registration: two lifecycle tests, five successful recorded registrations, and the course sum starter registered with its trace and complete instruction log.

  • Documentation browser: all eight lessons, command copying, 1,440 px desktop and 390 px mobile checks passed; no browser errors were recorded.

Reproduce and evidence

make perf-test

Laboratory shared tools

A separate server run using only the shared environment selected by source /tools/rv-lab/env.sh passed the same-ELF arithmetic comparison, 17/17 smoke outcomes, 47/47 full outcomes and 20/20 memory protocol cases. It used Python 3.11.7, RISC-V GCC 15.2.0, Spike 1.1.1-dev, Verilator 5.028 and host GCC 13.2.1. The shared tool tree contains 1,016 files; the permission check found no files or parent tool directories inaccessible to other users. Compiler caching is disabled in this shared environment, so it does not require a separate compiler-cache executable.
