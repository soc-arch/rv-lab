Directed frontend and predictor verification

Directed results cover all four presets: transport/ownership and redirect-fault behavior, 930 static-prediction vectors plus 36 core scenarios, and 723 backend successor/correction checks. The directed receipts and replay harness preserve the actual run and reproduction inputs. These runs use the imported RTL source identity.

The actual ant_j0 mul/div trace also contains 876 qualifying edges with retirement, IR admission, and successor-fetch acceptance together; its longest consecutive sequence has 11 edges. One measured sequence begins at cycles 6061–6063. This is an observation of that trace, not a promise of whole-program IPC=1. The summary preserves its trace hash and three sampled PC triplets.

Actual synthesis and Formality

Fresh real synthesis and RTL-to-gate Formality were rerun for all four imported presets. p1-rtl-gate-equivalence.json links actual source/configuration/library/tool/flow hashes, mapped netlist, SVF, reports and match/verify results.

  • Elaborated and mapped latch counts: 0 in every preset.

  • Unintended combinational loops and unmapped leaf cells: 0 in every preset.

  • Formality: 2,381 successful compare points per preset; failing, aborted and unverified points 0; black boxes 0.

  • The 32 unmatched reference storage bits are the unused x0 RF storage, reviewed explicitly. They are not failed compare points.

  • Synthesis warning counts match the prior reviewed source/preset results; the record does not claim a warning-free tool run.

Samsung LN28LPP libraries and commercial tool inputs remain private/read-only. The public provenance includes identities and results, not foundry files or proprietary netlists. Logical synthesis is not post-layout timing/signoff.

Reproduction and historical boundary

Select a fresh output root and actual configuration before the documented checks:

sh
export LAB_BUILD_DIR="$PWD/build/p1-check"
export LAB_CORE_PRESET=ant_j0
export LAB_MEMORY_ADAPTER=ii1
make doctor
make compare APP=01_arithmetic
make test
make camera-test
make visual-test
make perf-test
make registration-test

Use the eight lesson commands for the full student workflow, and reproducibility guide for browser/export gates. Set PYTHON=/usr/bin/python3.11 with Make when that is the working interpreter on the selected host; do not accidentally select an unrelated tool's python wrapper.

The historical teaching validation, historical JSON, and historical course results are kept for provenance. Their old one-entry-response-buffer CPU and cycle totals are not the default implementation or current measurement baseline.
