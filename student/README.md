# Your workspace

Put your own C and assembly files here. Labs 02–08 create these files from the
starters in `docs/course/starter/`. Labs 09–10 also create your own CPU copies
here (`student/lab09/rtl`, `student/lab10/rtl`) with `make lab09-init` and
`make lab10-init`.

Your programs and generated `build/` results are ignored by Git. Submit only
the files requested by your instructor; do not commit classmates' work or
generated run archives to the public teaching repository.
