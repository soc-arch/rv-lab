Only supplied measurements appear below. Missing timing is not treated as zero.

StepElapsed cyclesPixel countCycles / pixel

Cycles per pixel = supplied elapsed cycles ÷ the declared pixel count. Without a separate processed count, the denominator is every pixel in the output frame, including its border.

The ROI excludes the begin-marker store retirement and includes the end-marker store retirement. Helper instructions between those stores count. Total cycles also include setup, checking, and result publication.

Connect the image to the machine

  1. Copy: verify that input and output values agree before studying the load/store loop.
  2. Grayscale: follow channel arithmetic, shifts, and stores. Check how rounding is defined in the application.
  3. Edges: inspect neighborhoods and border handling, then find the repeated operations in the instruction trace.
  4. Extension idea: choose one costly repeated operation. Keep these input buffers and output checks when evaluating a custom instruction.
